## Icon Guidelines

### Design Requirements:
1. **Maskable Icons**: Design should work when masked to different shapes (circle, squircle, etc.)
2. **Safe Zone**: Keep important content within 80% of the center area
3. **Background**: Use solid background color or subtle gradient
4. **Contrast**: Ensure good contrast for visibility
5. **Simplicity**: Keep design simple and recognizable at small sizes

### Brand Colors:
- Primary: #3b82f6 (Blue)
- Background: #ffffff (White)
- Text: #1f2937 (Dark Gray)

### Tools for Icon Generation:
- [PWA Builder](https://www.pwabuilder.com/) - Auto-generate PWA icons
- [Favicon.io](https://favicon.io/) - Generate favicons and icons
- [Real Favicon Generator](https://realfavicongenerator.net/) - Comprehensive favicon generator

## Quick Setup:
1. Create your base icon (512x512) with the ORDERS.ID logo/branding
2. Use an online PWA icon generator to create all required sizes
3. Replace this README with your actual icon files
4. Test PWA installation on mobile devices

Note: Until real icons are added, the PWA will work but may show default/broken icon placeholders.
